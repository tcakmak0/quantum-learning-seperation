# Files and Navigation

- **`aQa_Leiden_Project_report_final.pdf`**  Full technical report (~20 pages). Contains every technical detail of the project. Markdown sections in the notebooks are kept minimal; refer to the report for explanations.

- **`demo.ipynb`**  Demo notebook walking through the main pipeline. Uses a selected subset of functions from `qml_lib.py`.

- **`experiments.ipynb`**  Experiments and their visualizations. Results are saved in the `results/` folder in pickle format, so you don't need to re-run the long experiments to reproduce the plots.

- **`qml_lib.py`**  Library containing all the machinery needed for the project. The demo notebook made of selected functions from  this file.

- **`results/`**  Pickled outputs from `experiments.ipynb`.
